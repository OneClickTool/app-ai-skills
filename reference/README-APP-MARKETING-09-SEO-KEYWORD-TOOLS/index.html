    SEO + ASO keyword — skill nào dùng được, tool nào miễn phí (kiểm 2026-10-08)¶

    Mục đích: trước khi viết blog / listing phải có keyword người thật đang gõ. File này ghi skill + tool đã kiểm tận tay, cái nào chạy, cái nào hỏng, cái nào chỉ là gợi ý chưa thử. Ví dụ áp dụng: apps/ACTIVE/markdown-viewer/marketing/blog-plan.md.

    1. Skill đang có (local)¶

    Skill Làm gì Kiểm 2026-10-08 Kết luận
    oneclicktool-blog (~/.claude/skills/) keyword (Autocomplete + Trends + SERP) → dàn ý → viết → check → build keywords.py --expand chạy tốt: 14 seed → ~2.500 gợi ý Dùng chính. Đã đủ quy trình "không đo không viết"
    Google Trends MCP (mcp__google-trends__*) so độ lớn tương đối, related/rising queries chạy được; gọi song song 5 lệnh → lỗi 429 gọi từng lệnh một; keyword dính quảng cáo (vd vibe coding 3 tháng) thì related ra rác — đọc kỹ trước khi tin
    Search Console MCP (mcp__search-console__*) query thật mà site đang có, vị trí 5–20 hỏng: thiếu ~/.config/gcp/oneclicktool-sa.json (thư mục rỗng từ 01/10) user tạo khoá service account → thêm email SA vào GSC (Full) + GA4 (Viewer). Claude không tạo/đọc khoá
    scripts/store_research.py hints (repo này) Autocomplete App Store (ASO) chạy: "markdown" → markdown reader, markdown editor and reader, markdown file reader… dùng cho listing/ASO; đã có search, mine (review), macchart
    app-research, app-listing, app-macos-listing, app-indie nghiên cứu kệ store, ASO listing có sẵn trong pipeline dùng như cũ

    3. Tool keyword miễn phí¶

    Trạng thái: đã dùng = chạy trong phiên 2026-10-08 · chưa thử = theo nguồn công khai, cần mở thử trước khi tin.

    Tool Cho cái gì Giới hạn Trạng thái
    Google Autocomplete (keywords.py) người thật đang gõ gì không có lượng đã dùng
    Google Trends (MCP) so tương đối, đang lên/xuống, rising 0–100, không phải lượng; 429 nếu gọi dồn đã dùng
    WebSearch / xem SERP ai đứng top, dạng bài, chỗ trống — đã dùng
    App Store autocomplete (store_research.py hints) keyword ASO iOS/Mac không có lượng đã dùng
    Google Search Console query + vị trí + click thật của site mình chỉ site mình, cần khoá hỏng — chờ khoá
    Google Keyword Planner lượng tìm kiếm theo khoảng (vd 1K–10K) cần tài khoản Google Ads; không chạy ads thì chỉ có khoảng chưa thử
    Bing Webmaster Tools → Keyword Research lượng tìm kiếm (dữ liệu Bing) cần xác minh site chưa thử
    Keyword Surfer (extension Chrome) lượng ngay trên trang Google — chưa thử
    AlsoAsked câu hỏi "People also ask" → FAQ 3 lần/ngày chưa thử
    Firecrawl keyless (qua skill aaron) top 10 SERP dạng dữ liệu ~1.000 credit/tháng chưa thử
    Wikipedia pageviews API proxy nhu cầu theo chủ đề không phải lượng search chưa thử
    Reddit search (app-research mine, app-reddit) người dùng tả nỗi đau bằng chữ của họ — đã có trong pipeline

    ASO riêng (App Store / Mac App Store):

    Tool Cho cái gì Trạng thái
    store_research.py hints/search/mine autocomplete, ai đang xếp hạng, review 1–3★ đã dùng
    Apple Ads (Search Ads Advanced) → keyword "popularity" độ phổ biến keyword do chính Apple đưa (5–100) chưa thử — cần tài khoản Apple Ads, tạo campaign nháp không phải trả tiền
    Astro (app Mac ASO), AppFigures, AppTweak, Sensor Tower popularity/difficulty, theo dõi thứ hạng chưa thử — bản đầy đủ trả phí, có bản dùng thử/free giới hạn

    Luật: không ghi "10K searches/tháng" khi chỉ có Autocomplete/Trends. Có số lượng thật (Keyword Planner, Apple Ads, GSC) mới ghi, kèm nguồn + ngày.

    4. Việc tiếp theo¶

    1. User tạo khoá GSC (mục 1) → mỗi 28 ngày lấy query vị trí 5–20 của oneclicktool.app.
    2. Thử Bing Webmaster Keyword Research + Keyword Planner cho 12 keyword trong blog plan Markdown Viewer → ghi lượng vào documents/blog-keywords.csv của web.
    3. Nếu viết nhiều trang so sánh: cài thử competitors, so bài #1 viết theo skill đó với bài viết theo oneclicktool-blog.
