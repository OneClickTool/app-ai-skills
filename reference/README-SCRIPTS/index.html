    README-SCRIPTS — script dùng chung¶

    Mọi script chạy từ gốc repo, Python 3 thư viện chuẩn (+ Pillow để đo ảnh) hoặc bash. Chạy độc lập không cần Claude. Checker: exit 0 = không FAIL, WARN không chặn; --quiet chỉ in dòng tổng kết (router dùng).

    Router¶

    Script Bước Làm gì
    scripts/app.py init --slug --name --bundle-id [--label --stack flutter\|native\|macos --platforms ios,android\|macos --distribution direct\|mas --research] 1 tạo apps/ACTIVE/<slug>/ + app.json + mọi template (stack macos lấy macos_listing.md thay listing.md)
    scripts/app.py status <slug> [--no-write] mọi bảng 14 bước, bước tiếp theo, thay đổi đang mở; ghi vào state.md
    scripts/app.py next <slug> · list mọi tên skill tiếp theo · danh sách app
    scripts/app.py log <slug> "việc" --skill app-x --next "..." mọi thêm dòng nhật ký vào state.md
    scripts/app.py change <slug> --type feature\|fix\|chore --title "..." [--version X.Y.Z] sửa / thêm việc tạo plan trong plan/update/v<X>/<type>/ (đã live) · plan/mvp/ (chưa live) · changes/ (chưa vào quy trình)
    scripts/android_upload_key.py <slug> [--show] 9 người dùng tự chạy: tạo upload key Android cho Play App Signing, mật khẩu cất Keychain (android-upload-<slug>), ghi file properties ngoài git; --show lấy lại mật khẩu
    scripts/sync_skills.py [apply] sửa skill so .claude/skills/ (nguồn) với .agents/skills/ (Codex): liệt kê skill lệch, exit 1; apply chép lại nguyên văn + dòng ghi chú; không đụng skill core/growth chỉ có ở .agents
