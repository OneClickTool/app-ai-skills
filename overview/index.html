    App AI Skills — pipeline Claude cho người không biết code làm app bán subscription¶

        +==============================================================+
    |                            /app                              |
    |              (skill cha: doc state.md, chi buoc ke)          |
    |                              |                               |
    |  0 setup -> 1 research* -> 2 money -> 3 spec* -> 4 design*   |
    |                                                    |         |
    |                                        4b mockup <-+         |
    |                                           |                  |
    |  8 review* <- 7 run <- 6 build (lap) <- 5 scaffold           |
    |     |                                                        |
    |     +-> 9 release -> 10 listing -> 11 publish                |
    |                         -> 12 marketing -> 13 grow (lap)     |
    |                                                              |
    |  sau ra mat: app-feature . app-fix      * = GATE ban duyet   |
    +==============================================================+

    Mục tiêu¶

    Bộ skill Claude Code cho người không biết lập trình: một pipeline dẫn đi hết đường làm app đàng hoàng — tìm ý tưởng → tính chuyện tiền → thiết kế → code → kiểm → lên App Store + Google Play → marketing → tăng trưởng. Claude làm phần kỹ thuật và giải thích bằng lời thường; bạn quyết ở 4 cổng và học được cả quy trình.

    Không làm: game (→ game-AI-skills); không tự đăng nhập / trả phí tài khoản Apple, Google, RevenueCat thay bạn.

    Muốn Gõ
    Chưa biết bắt đầu từ đâu / làm tiếp /app
    Thêm tính năng cho app đã live /app-feature
    Sửa lỗi app đã live /app-fix

    Bắt đầu nhanh¶

    Cần có sẵn: Claude Code · macOS + Xcode (iOS/Mac) · Android Studio (Android) · Python 3. Flutter được /app-setup cài qua fvm sau khi hỏi.

    git clone https://github.com/nvminhtu/app-AI-skills.git && cd app-AI-skills
python3 scripts/app.py list              # các app đang làm
python3 scripts/app.py status <slug>     # app đang ở bước nào, bước kế là gì

    Rồi trong Claude Code gõ /app (hoặc nói "tôi muốn làm app bán subscription").

    Pipeline¶

    # Skill Làm gì Output GATE
    0 app-setup Kiểm máy, cài Flutter, checklist tài khoản setup.md
    1 app-research [niche] [--mac] Đo kệ (iPhone hoặc Mac) + nhu cầu thật từ review/autocomplete/Reddit, chấm điểm, đề xuất một ý research/<niche>.md · <slug>/brief.md ◆ CỔNG 1 — bạn duyệt đề xuất (--ask để chọn ngay)
    2 app-money Free vs Pro, gói tháng/năm, vị trí paywall money.md
    3 app-spec Tính năng + khác biệt Free/Pro spec.md ◆ CỔNG 2 — app gồm gì
    4 app-design Giao diện, design token design.md ◆ CỔNG 3 — trông thế nào
    4b app-mockup Ảnh mockup từng màn (Codex sinh) để dev code bám theo mockup.md · design/mockup/
    5–7 app-scaffold → app-build ↻ → app-run Dựng project, code theo spec + test, chạy chụp màn app/ · run/
    8 app-review Soát trước khi ký review.md ◆ CỔNG 4 — đủ tốt để nộp
    9–11 app-release → app-listing → app-publish Ký build, trang store, nộp build · listing.md · publish.md
    12–13 app-marketing → app-grow ↻ Ra mắt, đo và tăng trưởng marketing.md · grow.md

    Stack mặc định Flutter (một code cho iOS + Android); nhánh Native (Kotlin/Compose + SwiftUI) khi cần tính năng OS sâu; macOS cho app Mac để bàn. Subscription qua RevenueCat. Từng bước bạn làm gì / Claude làm gì: README-PIPELINE.md.

    Chi phí và thời gian thật¶

    Khoản Chi phí Chờ
    Apple Developer Program 99 USD/năm ~24h; thuế + ngân hàng để bán subscription có thể tới 90 ngày
    Google Play Console 25 USD một lần xác minh vài ngày; tài khoản cá nhân phải closed test ≥ 12 người × 14 ngày
    RevenueCat 0 tới 2.500 USD doanh thu/tháng ngay
    Website Privacy/Terms/Support 0 (GitHub Pages) 1 buổi
    Phí store trên doanh thu 15% (Apple Small Business Program — phải đăng ký · Google subscription)
    App Review lần đầu — Apple thường ≤ 24h, tài khoản mới hay 2–5 ngày

    Mở tài khoản ngay ngày đầu — các đồng hồ chờ chạy song song với lúc làm app.
